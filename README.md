# 🦖 Raptor Performance

Página institucional de uma oficina especializada em performance automotiva.
Projeto desenvolvido para a disciplina de Desenvolvimento Web, com foco em
HTML semântico, estilização em CSS e **layout responsivo mobile-first**.

## 📄 Seções da página
- **Sobre** — apresentação da oficina
- **Serviços** — lista dos serviços oferecidos
- **Agendamento** — passo a passo para agendar

## ✨ Recursos
- **Layout responsivo (mobile-first):** a estrutura é pensada primeiro para
  celular e se adapta a telas maiores.
- **Flexbox** no menu de navegação (empilhado no celular, em linha no desktop).
- **CSS Grid** na seção de serviços (1 coluna no celular, 2 em telas maiores).
- **Media query** com breakpoint em 768px para reorganizar o layout.
- **Unidades relativas** (rem, %, fr) e efeito *hover* nos links do menu.

## 🛠️ Tecnologias
- HTML5 (tags semânticas)
- CSS3 (Flexbox, Grid, media queries)

## 🚀 Como visualizar
Clone o repositório e abra o arquivo `index.html` no navegador.
